# ✅ Visualart — Master Setup Checklist

A single printable list. Tick boxes as you go. Details for any item are in
[`README.md`](README.md) and the [`instructions/`](instructions/) folder.

---

## Phase 1 — Gather information (with Mom & Brother)
- [ ] Business **name** chosen + 2 backups
- [ ] **Tagline** chosen
- [ ] **`.com` domain** available (checked)
- [ ] **Instagram handle** available (checked)
- [ ] Mom's **photographs** collected (full-resolution originals saved safely)
- [ ] **Fulfillment email** inbox created (brother can access)
- [ ] **Contact email** chosen
- [ ] **PayPal** account ready + **PayPal.me handle** claimed
- [ ] **Cash App** account ready + **$Cashtag** set
- [ ] Brother created a **Pictorem** account
- [ ] **Pricing** decided (or using built-in formula)

## Phase 2 — Accounts
- [ ] **Domain** purchased (auto-renew ON, WHOIS privacy ON)
- [ ] **Hosting** account created (Netlify recommended)
- [ ] Site **deployed** to a temporary host URL
- [ ] **Order delivery** set up (EmailJS keys filled in OR FormSubmit chosen)
- [ ] FormSubmit **activation** email clicked (if using FormSubmit)

## Phase 3 — Make it yours
- [ ] Real **photos** added to `assets/photos/full` + `/thumbs`
- [ ] `data/photos.json` built (`npm run catalog:local`) and `npm run validate` passes
- [ ] **Titles / collections / tags** look clean
- [ ] Best pieces marked `"featured": true`
- [ ] `config.js`: **brand name + tagline**
- [ ] `config.js`: **fulfillmentEmail**
- [ ] `config.js`: **PayPal + Cash App handles**
- [ ] `config.js`: **pricing** reviewed on real product pages
- [ ] `config.js`: **contact email + Instagram**
- [ ] **Accent color / logo** adjusted (optional)
- [ ] **Privacy** + **Refund/Shipping** policies published & linked

## Phase 4 — Launch
- [ ] **Custom domain** connected to host
- [ ] **HTTPS padlock** 🔒 showing
- [ ] `yourdomain.com` **and** `www.yourdomain.com` both load
- [ ] ✅ **Full test order** placed end-to-end (real small payment to yourself)
- [ ] Order **email received** with all details + payment proof
- [ ] Brother did a **test Pictorem order**
- [ ] **Contact form** tested
- [ ] Checked on **phone + desktop**, **2 browsers**, **light/dark theme**
- [ ] **Soft launch** to friends/family
- [ ] **Announced** publicly (Instagram + circles)

## Phase 5 — Ongoing
- [ ] Brother knows the **fulfillment routine**
- [ ] **Order log** spreadsheet started
- [ ] **Backups**: project in GitHub + originals in cloud storage
- [ ] **Analytics** added (optional)
- [ ] Reminder set to confirm **domain renewal** yearly
